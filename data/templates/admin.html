THOR Guard Red Alert Policy

                                

                                

                                    
When Red Alert is active, critical safety audio takes priority until All Clear is received.

                                    

                                        
                                        
                                    

                                    

                                        
                                        
                                    

                                    

                                        
                                        
                                    

                                    

                                        

                                            
                                            
                                        

                                        

                                            
                                            
                                            
                                            
File in static/mp3/lightning/. Type a custom filename if needed.

                                        

                                    

                                    

                                        
                                        
                                    

                                    
                                    
                                    

                                

                            

                        

                        
                        

                            

                                

                                    
Lightning Alert Types

                                

                                

                                    

                                        🔴 Red Alert:
                                        Extreme danger - immediate shelter required
                                        Cancels the queue and blocks non-emergency announcements until All Clear.
                                        
                                    

                                    

                                        🟡 Warning:
                                        Lightning activity detected - use caution
                                        
                                    

                                    

                                        🟠 Caution:
                                        Developing lightning risk — announcement only, no lock
                                        
                                    

                                    

                                        🟢 All Clear:
                                        Sounds only if the previous condition was Red Alert, then releases the lock
                                        
                                    

                                    

                                        
                                        Clears the cached condition, Red Alert lock, and reminder timer
                                    

                                    
                                    

                                    
                                    
System Information

                                    

                                        The system monitors XML data for a <lightningalert> tag and plays announcements when conditions change.
                                    

                                    

                                        During Red Alert, a reminder repeats on the configured interval until All Clear. Emergency and lightning/weather announcements are still allowed.
